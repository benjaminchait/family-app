# family-app

A private iOS app for tracking a newborn's feeding and diapers, shared between two parents via iCloud. Not on the App Store; distributed through a personal Apple Developer account.

**Status:** planning. See [PLAN.md](PLAN.md) for scope and architecture, and [QUESTIONS.md](QUESTIONS.md) for the pre-build decision list — all 28 questions get answered before any Xcode/Swift is written, then a `SPEC.md` becomes the one-shot build prompt.
